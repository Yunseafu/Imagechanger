Imagechanger

给旧 iPhone 拍的 HEIC 补上「摄影风格」调色板数据。处理在你的浏览器里完成,照片不会上传。

实验性,未经真机验证。 先备份原图。处理后是否出现调色板,需要你在 iOS 27 的「照片 → 编辑」里确认。
选择或拖入 HEIC 原图 可多选 · Live Photo 请用「从文件选择」把同名的 HEIC 和 MOV 一起选 · 已带风格数据的照片会跳过

    提示"你上传的是 JPEG"?

    iOS 从相册选照片时常会把 HEIC 自动转成 JPEG,网页拿不到原图。请改用上面的「从文件选择」:先在「照片」里把原图存到「文件」(分享 → 存储到文件),或用 AirDrop 发到「文件」,再在页面里选它。若坚持用相册:选图界面左下角「选项」里选「当前」/「全部照片数据」。另外要确认 设置 → 相机 → 格式 为「高效」。

    Live Photo

    Live Photo 由一张 HEIC 和一段同名 MOV 组成。把两者一起选中,页面只给 HEIC 补风格数据,MOV 原样带回并按同名保存。传回 iPhone 时把两个文件一起存入相册(AirDrop 同时接收,或在「文件」里多选 → 存储到相册),系统会靠内部标识自动重新配对成 Live Photo。

    传回 iPhone 的正确方式

    1. 用 AirDrop 或「文件」App 保存结果,再在「文件」里点按图片 → 存储图像。
    2. 不要经微信/邮件压缩转发,那会重编码并丢掉附加数据。
    3. iPhone 设置 → 相机 → 格式 选「高效」,否则拍出来是 JPEG,无法处理。

    想直接从「照片」处理?

    网页拿不到相册原图,请用「分享 → 快捷指令」:从照片直接处理。

    想用 Siri 自动处理?

    在家里电脑/NAS 上运行本地服务,再建一个快捷指令即可,见 Siri 指南。
