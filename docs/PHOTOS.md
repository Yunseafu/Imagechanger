# 从「照片」直接处理(推荐)

网页的文件选择器在 iOS 上经常把相册里的 HEIC 自动转成 JPEG,网页无法阻止。
**快捷指令不受此限制**:它从「照片」分享菜单拿到的是原始 HEIC(Live Photo 会连同视频一起给出)。

两种做法,二选一:

| | A. 家里电脑/NAS 当服务器 | B. 全在 iPhone 上(a-Shell) |
| --- | --- | --- |
| 需要 | 一台常开的电脑或 Docker 主机 | 免费 App「a-Shell」 |
| 离开家 | 不能用(仅局域网) | 能用 |
| 成熟度 | 服务器已有测试 | **未在 a-Shell 实测**,需你试 |

---

## 方案 A:分享菜单 → 本地服务器

先按 [SIRI.md](SIRI.md) 启动服务器(`docker compose up -d` 或 `imagechanger serve`)。然后新建快捷指令「摄影风格」,**不要**加"选择照片",改为接收分享:

1. 快捷指令设置(右上 ⓘ)→ 打开「在共享表单中显示」,接受类型只勾「**图像**」。
2. 动作 0(让 Siri 也能用):**如果** 快捷指令输入 **没有任何值** → **选择照片**(开启「选择多项」)→ **否则** → 什么也不做 → 结束如果。这样从分享菜单进入直接用所选照片,对 Siri 说「摄影风格」则弹出选图器。
   动作 1:**重复 快捷指令输入 中的每个项目**(如果走了「选择照片」分支,则用「照片」变量;可在动作 0 里把两个分支都存入同一个变量「图片」,后面都用它)。
3. 动作 2:**获取 URL 内容**
   - URL `http://<服务器IP>:8765/patch`,方法 POST,请求体「表单」,字段:类型「文件」,键 `photo`,值「重复项目」。
4. 动作 3:**获取文件的详细信息 → 文件扩展名**(对象:URL 的内容)。
5. 动作 4:**如果** 扩展名 是 `heic` → **存储到相簿**(URL 的内容);**否则** → **显示通知**(URL 的内容,里面是原因)。
6. 结束重复。

用法:照片 → 选一张或多张 → 分享 → **摄影风格**;或对 Siri 说「**摄影风格**」。

注意:共享表单里的图片若被快捷指令换成 JPEG,服务器会返回 415;请确认「设置 → 相机 → 格式 = 高效」,并且不要在快捷指令里加「转换图像」。

## 方案 B:全部在手机上(a-Shell)

本项目只用 Python 标准库,可以直接在 a-Shell 里跑。

1. App Store 安装 **a-Shell**(免费)。
2. 把本仓库下载为 ZIP(GitHub → Code → Download ZIP),在「文件」App 里解压,放到 a-Shell 的文件夹里(「文件」→ 在我的 iPhone 上 → a-Shell)。
3. 在 a-Shell 中确认能运行:
   ```
   cd imagechanger-main
   python -m imagechanger inspect 某张.heic
   ```
4. 新建快捷指令「摄影风格」,同样开启「在共享表单中显示」(接受图像):
   - **存储文件**(共享表单输入)→ 目的位置 a-Shell 的 `in/` 文件夹。
   - **Execute Command**(a-Shell 的动作):`cd imagechanger-main; python -m imagechanger patch ../in/photo.heic ../out/photo.heic`
   - **获取文件**(a-Shell 的 `out/photo.heic`)→ **存储到相簿**。

a-Shell 的动作名称和沙盒路径随版本略有差异,若某一步报错,把报错发来调整即可。

---

## 两个共同的注意

- **"存储到相簿"是否保留附加数据**需你在真机确认:保存后打开「照片 → 编辑」看有没有风格调色板。若没有,说明系统保存时重新编码了,改用「存储文件」到「文件」App,再手动导入。
- **Live Photo**:分享菜单只给出静态图,处理后会丢掉配对的视频。需要保留 Live Photo 时,用网页的「从文件选择」同时选 HEIC 与 MOV。
