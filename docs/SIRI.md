# Siri / 自动化快捷指令

前提:电脑(或家里的 NAS/树莓派)已运行本地服务器,见根目录 [README](../README.md)。iPhone 与服务器须在同一 Wi-Fi。

## 1. 创建快捷指令「摄影风格」
快捷指令 App → ＋,依次添加:

1. **选择照片**(可开启"选择多项",后面加"重复每个项目"即可批量)
2. **获取 URL 内容**
   - URL:`http://<服务器局域网IP>:8765/patch`(IP 在服务器启动日志与 `http://<IP>:8765/` 页面上都会显示)
   - 方法 POST → 请求体"表单" → 新字段:类型"文件",键 `photo`,值为上一步的"照片"
3. **获取文件的详细信息** → "文件扩展名",对象为"URL 的内容"
4. **如果** 扩展名 是 `heic`:**存储到相簿**(URL 的内容);**否则**:**显示结果**(显示失败原因)

## 2. 用 Siri 调用
快捷指令名称就是唤醒词。把它命名为"摄影风格",然后说:"嘿 Siri,摄影风格"。
Siri 会弹出照片选择器,选图后自动处理并存入相册。

## 3. 其他触发方式
- **分享菜单**:快捷指令设置 → 在共享表单中显示,接受"图像"。相册里选图 → 分享 → 该快捷指令。
- **操作按钮 / 控制中心 / 主屏幕小组件**:在快捷指令设置里添加。
- **自动化**:快捷指令 → 自动化 → 个人自动化 → 例如"当连接到家里的 Wi-Fi 时",动作:
  查找照片(最新 N 张)→ 重复每个项目 → 同上步骤 2-4。
  注意:iOS 对相册自动化有限制,完全无人值守不一定可靠,建议用 Siri/分享菜单手动触发。

## 注意
- 必须发送**原始 HEIC**。设置 → 相机 → 格式 → **高效**;"选择照片"的操作里不要让它转成 JPEG。
- 服务器返回 409 表示无需处理(照片已带风格数据,例如 iPhone 16+ 原生照片)。
- 通过"文件"App/AirDrop 传回的 HEIC 才能保留附加数据;经相册重新导入以外的路径可能被重编码。
  "存储到相簿"这一步是否保留附加数据需你在真机验证。
- 服务器**没有登录**,只在自家局域网使用,不要映射到公网,也不要使用别人提供的服务器地址。
